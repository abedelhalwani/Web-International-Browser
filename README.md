# Web International Browser

A free Windows browser with tabbed browsing, built on WebView2.

## Download

[**Download for Windows (ZIP)**](https://abedelhalwani.github.io/Web-International-Browser/WebInternationalBrowser-Windows.zip)

Website: https://abedelhalwani.github.io/Web-International-Browser/

## Install

1. Download the ZIP and extract all files into a folder.
2. Open `WebInternationalBrowser.exe`.

The Microsoft Edge WebView2 Runtime must be installed. Windows may show a SmartScreen warning because the app is not code-signed: click **More info**, then **Run anyway**.
